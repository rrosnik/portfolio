# Portfolio

## How I have shown glb files (3D models) in this portfolio

- downloaded them from **[sketchfab.com](https://sketchfab.com)**
- optimized some of them using blender to make the 3D model objects more organized and have less mesh (triangles)
- converted them to jsx using gltfjsx package
- used **[react-three-fiber](https://github.com/pmndrs/react-three-fiber)** to render 3D models which uses **[three.js](https://github.com/mrdoob/three.js/)** package behind the scene:

## Stack

This portfolio project leverages a modern, high-performance technology stack designed for creating 3D web experiences:

### Core Framework & Build Tools

- **React 19** - Latest version of React for building interactive user interfaces
- **TypeScript** - Type-safe JavaScript for enhanced developer experience and code reliability
- **Vite** - Fast build tool and development server with hot module replacement

### Styling & UI

- **Tailwind CSS 4** - Utility-first CSS framework for rapid UI development
- **GSAP** - High-performance animation library for smooth transitions and effects

### 3D Graphics & Visualization

- **Three.js** - Powerful 3D graphics library for WebGL rendering
- **React Three Fiber** - React renderer for Three.js, enabling declarative 3D scenes
- **React Three Drei** - Useful helpers and abstractions for React Three Fiber
- **React Three Postprocessing** - Post-processing effects for enhanced visual quality

### Additional Libraries

- **EmailJS** - Client-side email sending for contact forms
- **React Countup** - Animated number counters for statistics
- **React Responsive** - Media query hooks for responsive design
- **React Toastify** - Toast notifications for user feedback

### Development Tools

- **ESLint** - Code linting for consistent code quality
- **TypeScript ESLint** - TypeScript-specific linting rules
